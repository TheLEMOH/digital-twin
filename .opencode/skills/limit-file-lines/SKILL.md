# Limit File Lines to 500

Примени этот скилл всегда, когда пишешь или редактируешь исходные файлы, чтобы ни один файл не превышал 500 строк.

## Правила

- Никогда не создавай файл длиннее 500 строк.
- Если правка может увеличить файл сверх лимита — разбей код на несколько файлов/модулей.
- При рефакторинге, если файл уже более 500 строк, вынеси части кода в отдельные файлы.
- Лимит применяется к любому исходному коду (`.ts`, `.js`, `.tsx`, `.vue`, `.css`, `.scss`, и т.д.).
- Прежде чем писать файл, оцени его предполагаемый размер; при сомнении — разбей заранее.

## Рабочий процесс

1. Оцени целевой размер файла перед написанием.
2. Если планируешь больше ~500 строк — продумай разбиение на модули заранее.
3. После создания/правки проверь количество строк (например, через `wc -l` или поиск по файлу).

## Разделение на модули

- Выноси вспомогательные функции, утилиты и константы в отдельные файлы (`utils`, `constants`, `types`).
- Разделяй большие компоненты на дочерние компоненты/секции.
- Для Vue-компонентов с длинным `<script>` — выноси логику в composables.
- Держи имена файлов осмысленными, отражающими их содержимое.

## Исключения

Лимит не применяется к:
- Сгенерированным файлам и файлам блокировок (`package-lock.json`, tarballs).
- Дампу данных / тестовым фикстурам.
- Если пользователь явно просит один файл больше 500 строк.
